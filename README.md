# 🌐 Browser Extension Manager UI

![Design preview for the Browser extensions manager UI coding challenge](./preview.jpg)

## Overview
In this challenge, I built a Browser Extension Manager UI based on a provided design and a `data.json` file.

The application allows users to manage their extensions through a clean, responsive and interactive UI.


---

## 🎯 What was required
The challenge asked me to:

- Dynamically display extensions using data from a JSON file
- Allow users to toggle extensions between active and inactive states
- Implement filtering (All / Active / Inactive)
- Allow users to remove extensions from the list
- Add a theme switcher (Light / Dark mode)
- Make the layout fully responsive for different screen sizes
- Implement hover and focus states for accessibility and better UX

---

## 🛠️ My Implementation
To complete this challenge, I built the project using **HTML, CSS and Vanilla JavaScript**.

I implemented:
- Dynamic rendering of extension cards from JSON data
- Toggle switch logic for activation and deactivation
- Filtering system (All / Active / Inactive)
- Remove extension functionality
- Dark and light mode with smooth transitions
- Responsive design using **Flexbox, Grid and Media Queries**
- Custom hover and focus effects for all interactive elements

---

## ✨ Result
The final result is a clean, responsive and interactive extension manager interface that closely matches the provided design and offers a smooth user experience.
